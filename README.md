# A collections test with a control group, on synthetic data

How I set up and read a test: does an action (an SMS, an extra call attempt, an AI agent) move payments, or would those customers have paid anyway?

## The method

1. **Define the metric first.** Here: share of customers who pay within 5 days.
2. **Assign at random.** The control group is chosen by the last digit of the ID number. It is simple, anyone can audit it, and it does not depend on the person running the campaign.
3. **Keep the control group working as usual.** Control is "business as usual", not "no management".
4. **Compare treatment against control**, with a confidence interval. If the interval includes zero, the test did not show an effect.
5. **Read it by segment.** An action can work in one portfolio and do nothing in another.

## Run it

```
python experiment.py
```

It only needs Python 3. It creates 20,000 invented customers in two portfolios, assigns 10% to control, simulates payments and prints the result.

## What the example shows

In portfolio A the action roughly doubles the payment rate. In portfolio B the difference is inside the margin of error. The decision that follows: keep spending on A, stop on B.

All data is generated by the script. No real customers, amounts or clients.
